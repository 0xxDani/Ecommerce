1*Registro
http://127.0.0.1:8000/api/register/{
    "username": "ejemplo1",
    "email": "testuser@example.com",
    "password": "1234567",
    "password2": "1234567"
}


2*Login
http://127.0.0.1:8000/api/users/login/
{
    "username": "ejemplo1",
    "password": "1234567"
    
}


3*Listar usuarios
http://127.0.0.1:8000/api/users/


4*Actualizar usuario por id(PUT): (Se debe cambiar el password)
http://127.0.0.1:8000/api/users/1/update/

{
    "username": "nuevo_nombre_usuario",
    "email": "nuevo_email@example.com",
    "password": "nueva_contraseña",
    "password2": "nueva_contraseña"
}

5*Eliminar usuario
http://localhost:8000/api/users/<id_del_usuario_a_eliminar>/delete/



6*Listar todos los productos (GET)
http://127.0.0.1:8000/api/products/


7*Ver detalle de un solo producto por ID (GET)
http://127.0.0.1:8000/api/products/1/


8*Crear un nuevo producto (POST)
http://127.0.0.1:8000/api/products/create/

{
    "titulo_producto": "Producto de ejemplo 2",
    "precio_venta": 100.0,
    "precio_con_descuento": 90.0,
    "descripcion": "Descripción del producto",
    "referencia": "P123",
    "pais_origen": "Colombia",
    "categoria": "RD"
}

9*Actualizar producto (PUT o PATCH)
Si usas PATCH, solo envías los campos que quieres modificar.
http://127.0.0.1:8000/api/products/1/update/

{
    "titulo_producto": "Producto actualizado",
    "precio_venta": 120.0,
    "precio_con_descuento": 100.0,
    "descripcion": "Descripción actualizada",
    "referencia": "P123-Actualizado",
    "pais_origen": "México",
    "categoria": "RM"
}


10*Eliminar producto (DELETE)
http://127.0.0.1:8000/api/products/130/delete/
